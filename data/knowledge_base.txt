Machine learning has three main types: supervised learning, unsupervised learning, and reinforcement learning. Overfitting happens when a model learns training noise, so it performs poorly on new data. The bias-variance tradeoff balances underfitting (high bias) and overfitting (high variance). Regularization like L1 and L2 penalizes complexity, and cross-validation estimates generalization by using multiple folds.

Backpropagation computes gradients by the chain rule. Convolutional Neural Networks (CNNs) are used for grid-like data such as images, and pooling layers reduce spatial dimensions while preserving key features. LSTM networks use gates to control information flow and reduce vanishing gradients. Common activation functions include ReLU, sigmoid, and tanh.

Transformers use self-attention to process sequences in parallel (Attention Is All You Need, 2017). Self-attention lets models weigh token relationships. BERT is a bidirectional transformer trained with masked language modeling and next sentence prediction. GPT uses autoregressive next-token prediction on large corpora. Transfer learning in NLP pre-trains models and then fine-tunes them. Instruction tuning aligns models to follow instructions, and RLHF uses human preference feedback.

Chain-of-thought prompting encourages step-by-step reasoning for complex problems. GPT-4 supports up to 128K tokens of context in extended-context variants.

Retrieval-Augmented Generation (RAG) combines a retriever with an LLM generator to answer questions grounded in external data. A RAG pipeline usually includes a document store, a retriever, and an LLM. Dense retrieval embeds queries and documents and uses vector similarity like cosine similarity. Chunking strategy affects retrieval precision and context window fit; common approaches include fixed-size, semantic, and hierarchical chunking. Advanced RAG techniques include re-ranking, query expansion, HyDE, and iterative or multi-hop retrieval.

Vector databases store and index high-dimensional embeddings for fast similarity search. FAISS is a library for efficient similarity search, supporting exact and approximate nearest neighbor algorithms. Text embeddings encode semantic meaning so similar texts map to nearby vectors. HNSW is a graph-based approximate nearest neighbor algorithm with logarithmic search complexity. Hybrid search combines dense vector search and sparse keyword search (BM25) using fusion methods like Reciprocal Rank Fusion.

LangChain is an open-source framework for building LLM applications, with components for chains, agents, and data connectors. LangChain Expression Language (LCEL) composes chains using the pipe operator, supporting streaming, async, and batching. LangGraph extends LangChain for stateful multi-actor apps as directed graphs with cycles. LangChain supports memory types such as ConversationBufferMemory, ConversationSummaryMemory, ConversationWindowMemory, and vector store memory. Retrievers in LangChain fetch relevant documents from data sources like vector stores or BM25.

LangSmith is a platform for debugging, testing, evaluating, and monitoring LLM applications. Traces capture inputs, outputs, latency, token usage, and errors for each component in a chain. The LangSmith Prompt Hub stores and versions prompt templates to support A/B testing and rollback. LangSmith datasets enable systematic evaluation of model or prompt changes. LangSmith monitoring reports latency percentiles, error rates, token costs, and feedback.

RAGAS evaluates RAG pipelines with metrics like faithfulness, answer relevancy, context recall, and context precision. Faithfulness checks whether answer claims are supported by retrieved context. Answer relevancy measures how well the answer addresses the question. Context recall measures coverage of ground-truth information. Context precision measures how much retrieved context is relevant to the answer.

Guardrails AI provides validation and safety checks for LLM outputs with configurable on-fail actions. PII (Personally Identifiable Information) includes data such as emails, phone numbers, SSNs, and credit cards, and it must be protected to avoid privacy violations. Structured output validation ensures responses conform to required schemas (for example, JSON). Constitutional AI uses a set of principles and self-critique to steer model behavior. Common LLM safety concerns include hallucination, toxicity, bias, PII leakage, and jailbreaking.
